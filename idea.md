

```id="cargo_bot_prompt_v2"
Создай Telegram-бота для карго-компании на Python с использованием aiogram 3.x и PostgreSQL.

Основная задача:
Бот уведомляет клиентов о прибытии их товаров на основе Excel-файла, загружаемого администратором.

--------------------------------------------------
1. Роли
--------------------------------------------------
- Админ:
  - Загружает Excel файл
- Пользователь:
  - Получает уведомления
  - Регистрируется в системе по коду клиента

--------------------------------------------------
2. Логика работы
--------------------------------------------------
1. Пользователь:
- При первом запуске (/start):
  - Получает:
    - Приветствие
    - График работы
    - Видео-инструкцию (ссылка или файл)
    - Инструкцию
  - Вводит свой "код клиента"
  - Бот сохраняет:
    - client_code
    - telegram_id
    - username

2. Админ:
- Использует команду:
  /upload
- После команды загружает Excel файл (.xlsx)

3. Обработка Excel:
- Использовать pandas или openpyxl
- Извлекать колонку B (коды клиентов)
- Игнорировать пустые значения
- Удалять дубликаты внутри файла

4. Уведомления:
- Для каждого client_code:
  - Найти пользователя в БД
  - Если найден:
    - Проверить, не было ли уже уведомления
    - Если нет → отправить сообщение:
      "Ваш товар прибыл, можете забрать"
    - Сохранить факт уведомления

--------------------------------------------------
3. База данных (PostgreSQL)
--------------------------------------------------

Таблица users:
- id
- client_code (unique)
- telegram_id
- username

Таблица arrivals:
- id
- client_code
- notified_at
- UNIQUE(client_code)  ← защита от дублей

--------------------------------------------------
4. Защита от дублей
--------------------------------------------------
- Не отправлять уведомление повторно для одного client_code
- Проверять через таблицу arrivals

--------------------------------------------------
5. UX (интерфейс)
--------------------------------------------------

Кнопки:
- 📦 Проверить статус (заглушка)
- ℹ️ Информация

Поведение:
- Если пользователь уже зарегистрирован → не спрашивать код снова
- Возможность обновить код клиента

--------------------------------------------------
6. FSM (обязательно)
--------------------------------------------------
Использовать FSM для:
- Ввода кода клиента
- Загрузки Excel админом

--------------------------------------------------
7. Проверки и безопасность
--------------------------------------------------
- Проверка, что Excel загружает только админ
- Проверка формата файла (.xlsx)
- Проверка наличия колонки B
- Обработка ошибок (пустой файл, неверный формат и т.д.)

--------------------------------------------------
8. Логирование
--------------------------------------------------
Логировать:
- загрузку файла
- количество обработанных строк
- сколько уведомлений отправлено
- ошибки

--------------------------------------------------
9. Архитектура проекта
--------------------------------------------------

Структура:

bot/
 ├── handlers/
 │    ├── user.py
 │    ├── admin.py
 ├── services/
 │    ├── excel_parser.py
 │    ├── notifier.py
 ├── database/
 │    ├── db.py
 │    ├── models.py
 │    ├── queries.py
 ├── keyboards/
 ├── middlewares/
 ├── config.py
 └── main.py

--------------------------------------------------
10. Функции (обязательно реализовать)
--------------------------------------------------

- add_user(client_code, telegram_id, username)
- get_user_by_code(client_code)
- save_arrival(client_code)
- is_already_notified(client_code)

--------------------------------------------------
11. Дополнительно
--------------------------------------------------
- Ограничение скорости отправки сообщений (антиспам)
- Поддержка большого файла (эффективная обработка)
- Чистый и расширяемый код

--------------------------------------------------
12. Результат
--------------------------------------------------
Выведи:
- Полный рабочий код проекта
- С комментариями
- Готовый к запуску
```
